# Support — Viridis Scope Desk

Use this source repository's public Issues tab when enabled to report a bug, ask a question or propose an improvement. Include the package version, host, selected skill, expected supplied rule and a minimal synthetic example. A native file button or unavailable source link is not evidence that a skill read the file.

Keep the selected baseline and original source text. Distinguish quoted facts, proposed scope decisions, historical test results, unexecuted checks and actual acceptance. A generated scope or change draft does not establish a client's agreement, a price, a completed test or a delivery.

Do not post credentials, private client briefs, account identifiers, personal information, internal CI records or confidential artifacts. For a possible security or privacy issue, post only a high-level description without sensitive or exploitable details. This package does not provide a private vulnerability-reporting channel or a promised response time.

See the [evidence rules](skills/scope-job/references/evidence-rules.md), [synthetic example](examples/README.md), [privacy notice](PRIVACY.md) and [MIT software license](LICENSE). No paid checkout, service-level agreement, production destination or account grant is included.
